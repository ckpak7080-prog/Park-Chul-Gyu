# 📊 아웃룩 주간보고서 PPT 자동 취합 및 병합 스크립트

**작성자:** 박철규

## 📝 프로젝트 목적
Windows 환경의 아웃룩(Outlook)에서 오늘 날짜(YYMMDD)가 포함된 부서별 주간보고서(PPT) 메일을 자동으로 스캔 및 다운로드하고, 지정된 순서에 맞게 하나의 PPT 파일(`주간보고병합.pptx`)로 자동 병합하는 업무 자동화 프로그램입니다.

## ✨ 주요 기능
- **날짜 필터링:** 당일 날짜(예: `260521`)가 파일명에 포함된 PPT(.ppt, .pptx)만 선별하여 다운로드
- **부서별 자동 매칭 및 누락 확인:** 다운로드된 파일명 및 보낸 사람을 분석하여 부서를 식별하고, 미제출 부서를 콘솔에 출력
- **순차적 자동 병합:** 표에 지정된 부서별 취합 순서(1순위~8순위)에 맞춰 슬라이드 오름차순 자동 병합

## ⚠️ 사전 요구 사항 (Prerequisites)
- **OS:** Windows 환경 (Mac/Linux 지원 불가)
- **Software:** Microsoft Outlook (계정 로그인 필수), Microsoft PowerPoint 설치 필수
- **Python:** Python 3.x 버전
